Política de privacidad

Última actualización: 7 de noviembre de 2026

Secretario es un asistente personal que usa una sola persona, su dueño. No se ofrece al público y solo la cuenta de Telegram de su dueño puede hablar con él.

Qué datos usa

  • Google Calendar: lee los calendarios del dueño y crea o borra eventos solo después de que el dueño aprueba cada acción.
  • Gmail: lee y busca los mails del dueño, crea borradores, y envía o archiva mails solo después de que el dueño aprueba cada acción.
  • Google Drive: busca y lee los archivos del dueño (solo lectura).
  • Los mensajes, audios, tareas, notas, contactos y gastos que el dueño le manda al asistente.

Para qué se usan y a dónde van

  • Los datos se usan únicamente para responder los pedidos del propio dueño.
  • Para generar las respuestas, el texto necesario se envía a la API de Claude de Anthropic. Los audios se envían a la API de OpenAI para pasarlos a texto, y las respuestas habladas se generan con esa misma API.
  • El permiso de Google, el historial de la charla, las tareas, notas y demás datos se guardan en una base de datos privada en el servidor del dueño (Railway).
  • Los datos nunca se venden, no se comparten con nadie más y no se usan para publicidad.

Datos de usuarios de Google

El uso que Secretario hace de la información recibida de las APIs de Google cumple la Política de datos del usuario de los servicios de API de Google, incluidos los requisitos de Uso Limitado.

Quitar el acceso y borrar los datos

El acceso a Google se puede revocar en cualquier momento en myaccount.google.com/permissions. Borrar la base de datos del asistente elimina todos los datos guardados.
